# Bicycle standardized level

Thirty-one standardised photographs, one for each suitable bicycle-theme source, cropped as reviewed and encoded with `tools/stimuli/standardise.py`. Each keeps its source's licence conditions, including credit and, for the Flickr photograph, non-commercial use. Sixteen versions of photographs later rejected for clarity are withdrawn; their records and hashes remain in the catalogue. Add further reviewed 512/256 px WebP files here, with new version IDs, parent references, hashes and transformation records. Standardise an edited master here before final selection.

See [index.json](index.json), the [catalogue](../../catalogue.json), and the mandatory [agent instructions](../../AGENTS.md).
