# Visual reference guide

These concept drawings show **three examples**, not three fully implemented rounds.

1. `01_bicycles.png`: Conventional visual recognition. Visually unambiguous bikes and non-bikes; the first simple test. This panel uses the clearest multiple-selection interaction.
2. `02_job_interview.png`: Semantic judgement with absurd animals. **Illustrative only:** several animals are wearing accessories, so “dressed for a job interview” is not guaranteed to have a unique objectively correct answer. Revise stimuli or instruction accordingly.
3. `03_sitting.png`: Functional category and bureaucratic absurdity. **Illustrative only:** “could reasonably sit on” is subjective; use “designed/intended for sitting” for scored or confirmatory trials, or explicitly classify this round as subjective.
4. `overview.png`: Full art direction; these are *panels displayed side by side for comparison*, not an instruction to display all three simultaneously in the actual game. Actual game shows **one challenge at a time**.

### Design intent
- Serious government-paperwork frame, fictional DHV seal, case ID, progress dots and neutral cream/navy/grey UI.
- Colourful photographic stimuli with crisp square-ish tile grid, broad spacing and distinct interactive states.
- Deadpan, formal British English; original verification jokes that do not mislead about real personal status.
- Improve proportions on mobile, keyboard access, colour contrast, focus and reduced motion.

### Explicit exclusions
- Do not embed these flattened panels as the actual website's working interface, nor crop the mock-up tiles as final test material.
- Do not treat these images as licensed/public research datasets or validated answer keys.
- Do not add a camera, biometric measurement, tracking, or an AI gaze-reveal to V1.
- Do not copy any real CAPTCHA brand's look or logo.

Refer to `department_of_human_verification_implementation_brief.md` for the authoritative implementation, experimentation, privacy, test and deployment requirements.
