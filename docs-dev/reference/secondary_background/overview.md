# Overview

*The Department of Human Verification* — non-binding orientation.

## What it is

A fictional bureaucratic CAPTCHA game: five visual assessments, scored with deadpan severity. Humanity cannot be self-certified.

## Stack

node-vite + typescript

## Scope and platform

A standalone browser game for desktop and phone browsers, served at `https://eelkedevries.com/department-of-human-verification/`. Version 1 is the game alone; version 2 adds optional webcam eye-tracking on desktop and laptop computers for a research question about instruction phrasing, gaze and image-based attention models. The binding design canon is `../primary_authoritative/specification.md`.

- `implementation_brief.md` — the owner's implementation brief for versions 1 and 2 (20 October 2026).
